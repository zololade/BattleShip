# TOP's Knight Traversal Project

This document demonstrates my comprehension of tree traversal algorithms and their practical application within a project context.

## Setup

### Prerequisites

- Node.js v18+

### Installation

1. Clone the repo and navigate into it
2. Install dependencies:

```bash
npm install
```

### Scripts

| Script | Command | Description |
| -------- | --------- | ------------- |
| Dev | `npm run dev` | Run and watch `src/index.ts` with tsx |
| Build | `npm run build` | Compile TypeScript to `dist/` |
| Start | `npm start` | Run compiled output with Node |
| Test | `npm test` | Run tests with Vitest |
| Test watch | `npm run test:watch` | Run tests in watch mode |
| Lint | `npm run lint` | Lint `src/` with ESLint |
| Lint fix | `npm run lint:fix` | Auto-fix lint issues |
| Format | `npm run format` | Format `src/` with Prettier |
